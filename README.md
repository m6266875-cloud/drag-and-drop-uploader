# drag-and-drop-uploader

A drag-and-drop image uploader built with vanilla **HTML, CSS, and JavaScript** — no frameworks or libraries. Built as part of my Frontend Development Internship at **Internee.pk**.

Users can drag images directly into the browser (or click to browse), see an instant preview, watch a simulated upload progress bar, and get clear feedback if they try to upload an unsupported file type.

## ✨ Features

- 🖱️ **Drag-and-drop upload** using the HTML5 Drag-and-Drop API
- 🖼️ **Live image preview** via the FileReader API
- 📊 **Simulated upload progress bar** (built with `setTimeout`)
- ✅ **File type validation** — only JPG, PNG, and GIF are accepted
- ⚠️ **Error messages** for invalid file uploads
- 💾 **Persistent storage** — uploaded images are saved with `localStorage`, so they're still there after a page refresh

## 🛠️ Built With

- HTML5
- CSS3 (custom properties, animations, responsive grid)
- Vanilla JavaScript (ES6+)

## 📚 Concepts Practiced

- Drag-and-drop events (`dragover`, `dragleave`, `drop`)
- Handling the `FileReader` API for image previews
- DOM manipulation and dynamic element creation
- Asynchronous behavior simulation with `setTimeout`
- Client-side file validation and error handling
- Browser storage (`localStorage`) for persisting data across sessions

## 🚀 Getting Started

No build tools or dependencies needed — it's a single self-contained HTML file.

1. Clone or download this repository
2. Open `contact-sheet-uploader.html` directly in your browser

```bash
git clone https://github.com/m6266875-cloud/drag-and-drop-uploader
cd your-drag-and-drop-uploader
```

Then just double-click `contact-sheet-uploader.html`, or open it via **Live Server** in VS Code.
